# От вопроса к данным

Учебный тренажёр по составлению анкеты. Показывает, как решения, принятые
при формулировке вопроса, определяют структуру будущей таблицы с данными.

Одна HTML-страница без зависимостей. Работает офлайн, ничего никуда не отправляет.

## Зачем он нужен

Второкурсник обычно думает, что сначала собирают «ответы», а потом «считают»,
и что одно с другим связано слабо. Тренажёр показывает обратное:

> Структура данных задаётся на этапе анкеты, а не на этапе анализа.
> После сбора ответов исправить её нельзя.

Поэтому каждый экран устроен одинаково: студент принимает решение — и сразу
видит, во что это решение превращается в таблице.

---

## Как устроен

Пять экранов, около 20 минут.

| Экран | Что делает студент | Что видит в ответ |
|---|---|---|
| 1. Цель и признаки | выбирает цель из трёх и отмечает признаки | каждый признак станет переменной; чего не спросили, того в данных не будет |
| 2. Ваш вопрос | **единственный свободный ввод:** формулирует вопрос и пять вариантов ответа | автоматическая проверка формулировки |
| 3. Типы вопросов | предсказывает, что получится из готовых вопросов | фрагменты таблиц: 0/1, искажённое среднее, пересекающиеся интервалы |
| 4. Паспортичка | отмечает допустимые формулировки | что из этого персональные данные |
| 5. Готовая анкета | скачивает текст анкеты | сравнение своей формулировки с исходной |

---

## Что делает автоматическая проверка

Свободный ввод есть только на втором экране, и проверка там намеренно узкая.

**Останавливает** (задание не выполнено):
- текст не похож на фразу на русском языке;
- в вопросе нет ни одного слова, относящегося к измеряемому признаку;
- варианты ответа не образуют шкалу запрошенного типа;
- это не вопрос: нет ни вопросительного знака, ни слова «оцените», «укажите».

**Сообщает о дефектах, видных по тексту:** пересекающиеся числовые интервалы,
повторяющиеся варианты, термины методологии («респондент», «валидность»),
наводящие формулировки («не правда ли»).

**Выносит на решение человека:** длину вопроса, союзы «и» / «или», чётное
число позиций шкалы, вариант «затрудняюсь ответить», профессиональные термины.

**Не делает ничего другого.** Проверка не знает, хороший получился вопрос или
плохой, и прямо сообщает об этом студенту. Каждое утверждение, которое она
выводит, — это проверяемый факт о тексте, а не оценка качества.

## Приватность

- Весь текст обрабатывается в браузере средствами JavaScript.
- Нет обращений к сети — ни при загрузке страницы, ни во время работы.
- Нет внешних библиотек, шрифтов и изображений.
- Нет `localStorage`, `sessionStorage`, cookie, аналитики и трекеров.
- Введённое живёт только в памяти вкладки: закрыли — исчезло.

Подробно: [personal-data.html](personal-data.html) и [terms.html](terms.html).

## Как выложить

Три файла в одну папку, страница тренажёра называется `index.html`:

```
├── index.html          ← тренажёр
├── personal-data.html  ← политика обработки персональных данных
├── terms.html          ← условия использования
├── LICENSE
└── README.md
```

Подойдёт любой статический хостинг: GitHub Pages, Netlify и т.п.
Сборка не нужна.

**Для компьютерного класса** надёжнее не ссылка, а файл: `index.html`
открывается двойным кликом с флешки и работает без интернета. Правовые
страницы при этом должны лежать рядом, иначе ссылки в подвале не откроются.

## Как сделать тренажёр по своей теме

Весь сценарий вынесен в один объект `DATA` в начале скрипта. Логику трогать
не нужно — меняется только содержание.

```js
var DATA = {
  theme:    'Название темы',
  goals:    [ /* три цели: { text, ok, why } */ ],
  signs:    [ /* шесть признаков: { text, ok, why } */ ],
  priznak:  'признак, который студент будет измерять своим вопросом',
  answerType: 'freq',          // тип шкалы, которую просят на экране 2

  core:  [ /* основы слов: о чём признак */ ],
  field: [ /* основы слов: предметная область */ ],
  freqWords: [ /* слова частоты для проверки шкалы */ ],

  human:       [ /* чек-лист «проверьте сами»: { t, d } */ ],
  passport:    [ /* шесть формулировок паспортички: { text, ok, why } */ ],
  rest:        [ /* готовые вопросы анкеты */ ],
  passportOut: [ /* блок паспортички в готовой анкете */ ]
};
```

Три задания третьего экрана лежат отдельно, в массиве `T3`.

**Самое важное при переносе — словари `core` и `field`.** На них держится
проверка «вопрос не о том, что вы измеряете». Указывайте основы слов, а не
слова целиком (`помощ`, а не `помощь`): поиск идёт по вхождению подстроки.
Слишком узкий словарь начнёт блокировать нормальные вопросы, слишком широкий
пропустит что угодно.

> Техническая оговорка: `\w` в JavaScript не покрывает кириллицу, поэтому
> в коде нигде не используется — только явные подстроки и класс `[а-яё]`.
> Если будете дописывать проверки, имейте это в виду.

## Чем он не является

Тренажёр не учит составлять анкеты и не заменяет курс по методике
социологического исследования. Свободная формулировка в нём ровно одна,
всё остальное — выбор с показом последствия. Его предмет — не анкета,
а происхождение структуры данных.
